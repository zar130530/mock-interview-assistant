## 二、项目描述（通用全栈版 · 可直接粘贴）

**Job Hunter 求职智能体系统**　|　独立全栈开发（开源）
- 从 0 到 1 设计开发一款面向求职场景的开源智能体系统：解析候选人简历、管理目标岗位，并基于 LLM 能力对"人岗匹配度"做四维评估与定向优化，最终一键生成可视化结果页，辅助求职决策。
- 实现多格式简历解析（PDF / Word / 图片）：图片走 OCR 降级通道，文本与图片统一进入 LLM 结构化抽取，输出标准化候选人画像，兼顾不同来源简历的可用性。
- 构建 4 维人岗匹配与定向优化引擎：调用 job-hunt 技能方法完成匹配计算与优化建议生成，并以内置规则引擎作为无 LLM / 异常时的兜底，保证结果稳定可复现。
- 完整后端工程实现：落地 25 个 REST 接口、线程池异步任务调度、结果缓存，并修复并发竞态问题；对上传文件做安全校验，降低恶意文件风险。
- 质量保障：编写 117 个 pytest 用例覆盖核心链路，全部通过（全绿）；代码已开源，README 可复现部署。
