## 一、项目名片

- **项目名称**：AI 面试助手智能体（Mock Interview Assistant）
- **担任角色**：独立开发（全栈 + AI 工程，从 0 到 1）
- **技术栈**：Python · FastAPI · SQLite · OpenAI 兼容大模型 API（GPT / DeepSeek / 通义 / 本地 Ollama）· RAG（关键词检索召回）· 原生 JavaScript（零构建）
- **代码规模**：后端 8 个 Python 模块 + 单文件前端（设计令牌驱动，无打包构建）

---

## 二、项目描述（通用全栈版 · 可直接粘贴）

**AI 面试助手智能体**　|　全栈独立开发
- 从 0 到 1 设计并实现一款基于大模型的模拟面试工具：上传简历 + 目标公司 JD，自动生成高仿真技术面试题（含标准/参考回答、考察点、评分要点），并基于真实 JD 做技能匹配度对齐（strong / partial / missing）。
- 设计关键词→算法标签映射的 RAG 召回机制，从内置 65 道力扣真实题库中按相关度检索题目注入生成上下文，杜绝大模型"编造算法题"，保证题目可验证、可练习。
- 基于 OpenAI 兼容接口对接多家大模型，采用 JSON 结构化输出 + 失败自动回退策略；并提供无 API Key 的 Mock 模式，确保离线/无密钥也能跑通完整链路，降低演示与联调成本。
- 实现对话式增量修改协议（append / update / delete 增量 diff）：用户可用自然语言追加、改写、删除题目；并支持作答后由模型打分点评，形成"出题—练习—反馈"闭环。
- 后端工程化：异步线程池 + 硬超时保护、统一异常处理与友好错误翻译、运行日志持久化；前端基于 CSS 设计令牌实现响应式布局、骨架屏、拖拽上传、Toast 反馈，覆盖桌面/平板/移动端。

---

## 三、突出 AI / RAG 工程版（投算法 / 大模型 / AI 应用岗）

- 构建 LLM 应用：以 OpenAI 兼容协议接入 GPT / DeepSeek / 通义 / Ollama 等模型，封装 JSON 模式输出与失败回退（JSON 模式失败自动降级普通模式再解析），支持多模型热切换。
- 设计轻量 RAG 召回：将 JD/简历中的技术关键词映射为算法标签，对 65 道真实力扣题做加权打分排序，把检索结果作为上下文注入出题 Prompt，缓解模型幻觉。
- 设计对话式增量修改协议：模型仅返回变更增量（added / updated / deleted），后端做 id 重排与持久化，保证前端详情页始终与最新状态一致。
- 设计多角色系统提示词（面试官出题 / 对话修改 / 口试评分），并通过约束性 JSON Schema 保证结构化输出稳定、可前端直接渲染。

## 四、一句话简介（作品集 / 简历摘要用）

面试助手智能体：一款基于大模型与 RAG 的模拟面试工具，输入简历 + JD 即可生成高仿真面试题与评分要点，支持对话式改题与 AI 打分复盘。

---

## 五、可量化的真实事实（可直接引用，均来自代码）

- 简历解析支持 **PDF / Word(.docx) / TXT** 三种格式，按内容 SHA-256 哈希去重复用。
- 内置 **65 道力扣真实算法题库**，覆盖数组、哈希表、动态规划、树、图等 30+ 标签。
- 题型覆盖 **5 类**：基础技术、实习/项目深挖（STAR 追问）、行为软素质、编码算法、业务场景。
- 后端 LLM 调用硬超时 **120s**、简历解析 **30s**；统一结构化 JSON 输出。
- 数据持久化采用 **SQLite**，核心表：resumes（简历）、interviews（面试记录）、user_answers（作答与评分）。
